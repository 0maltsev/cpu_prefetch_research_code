# Queue provenance records

These machine-readable records bind each mandatory Stage A queue to protocol
`2.0.0-pre.1`, its independent implementation files, no-source-reuse status,
repository no-license grant, semantic adaptations, atomic mapping, proof, tests,
and generated-code gate. `tools/check_queue_provenance.py` rejects missing
fields, changed implementation bytes, source reuse claims, or a falsely passing
dual-disassembler status.

The current FastFlow project is only an official-project search result. Its
current dual-license statement is not attributed to an unresolved exact 2010
paper artifact and no FastFlow implementation source may be consulted or used.
