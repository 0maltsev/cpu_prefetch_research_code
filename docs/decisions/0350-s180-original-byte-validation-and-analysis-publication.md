big-endian byte SHA256. Match the admitted original source artifact, every

## Exclusive durable output

`validate_and_publish_capture` requires an explicit output byte budget, remaining
original deadline, protected caller-owned nonsymlink parent and durable original
artifact URI/compression declarations. Output must be outside the original input
tree. Require actual free byte/inode capacity and a new exclusive private result
directory/lock. Existing directories are never adopted, overwritten or retried.
The qualified supervisor still must admit aggregate workspace, retained failures,
scratch, actual physical allocation, inodes, processes and original-day limits.
The primitive checks actual per-directory allocated/logical charge and18-object
ceiling; it explicitly grants no aggregate resource admission or archive custody.

Write two fresh unpublished candidates. Keep every candidate and a bounded
failure record on failure. After all checks and analysis pass, durably retain
the capture proof, numerical report and both PASSED join audits. The join core
already fsyncs and independently reads/hashes each complete derived stream.
Protect the held file descriptors read-only, publish without replacing a name,
and remove only the pending link to that same retained inode. No observation
or raw input is deleted. FD-based protection avoids unsupported path-chmod
flag combinations on older stand kernels.

Emit six external immutable producer/consumer/joined envelopes under the actual
unchanged protocol2.0.0-pre.3 raw-observation schema. Each has the exact run,
physical format/encoding, units, byte/row counts, hashes, ordering, compression,
storage URI and actual join-audit artifact reference. Joined envelopes name
the two original native source artifact IDs/hashes. Original URIs/compression
come from the caller-authenticated durable custody inventory; do not substitute
a temporary inverse-spool location. Joined URIs point to the retained published
uncompressed files. A later archiver must preserve resolvable immutable envelopes
and cannot delete their target as an unreferenced scratch copy.

Publish `complete.json` last after the actual output's bytes, metadata and
allocated charge have passed and preceding evidence is durable. A late failure
retains an uncommitted manifest and removes its successful-marker name; partial
files never imply success. Root replacement, unexpected objects, budget/deadline
failure and interrupted publication fail closed. The qualified parent must also
verify actual child completion and the retained bindings; a filename alone
never establishes family success or authorizes recovery/adoption.
