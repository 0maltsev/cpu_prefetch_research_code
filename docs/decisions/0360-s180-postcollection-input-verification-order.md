Accepted engineering composition of the existing independent inverse and
original-custody checks. Scientific observations, source/window/count rules,
archive representation, native collection/acknowledgements, physical/canonical
integrity requirements, limits and Stage18 authority remain unchanged.

D359 identified an omitted serial pass: D356 invokes the strict collection
registry on every original archive before D354 independently hashes and inversely
reconstructs those bytes again in the12 owned workers. At large sizes this adds
unaccounted serial payload I/O to the90-minute analysis stage. Collection already
completed its original strict registry, verified archive publication/release and
durable parent receipt before each native ACK; that route must stay strict.

Extract the common original ledger/capture verification body privately. The
existing public collection function always supplies the existing full physical
hash checker. A separate analysis-only entry requires the actual same-process
post-restoration analysis owner, its exact unconsumed plan and original deadline.
It verifies every original checkpoint/receipt/ledger registration, released state,
role, archive path, extent/link identity, header and stable file identity. It
returns a versioned **pending analysis input** with continuation_allowed=false,
physical_sha256_verification_pending=true and independent_inverse_required=true.
It supplies no fresh payload hash, native continuation or successful dataset.
Any preparation error latches the original analysis phase; there is no retry.

The same actual owned inverse workers still read/hash every physical archive,
decompress/reconstruct every canonical byte and check original canonical hashes
before independent controls/raw/numerics validation or durable publication.
Corruption after input preparation fails the original decoder and retains its
failed spool. The parent still requires actual worker completion/cleanup and
post-reap output bindings before final family validation. No original or failed
raw is removed by this change, and no hash comparison is replaced by a receipt.

Pool/capture/family data-contract readers recognize the explicit pending input
without upgrading its native-continuation or physical-validity flags. The pure
family validator continues to disclaim actual custody/supervision authority.
Only D356's actual inverse/pool/family composition establishes final custody;
its outer report becomes version3 and records the actual verification order.
Final live readbacks remain mandatory, signed operational exit remains separate,
and no inference or Stage18 authority follows.

The analysis-only module is outside the archive broker's source roots. The
strict archive component closure stays29 modules and does not absorb the owned
analysis-phase/environment implementation. Its changed registry bytes require a
fresh clean component binding before use; the D359 component remains historical.
Frozen native34247ce and the existing encoder/codec images remain unchanged.

Targeted tests use real original synthetic archive registration and actual
dedicated inverse workers, with explicit typed-phase test doubles at the owned
phase boundary. They check that pending inputs cannot grant continuation or
disable inverse verification, missing archives and bad owners/deadlines fail,

Whole-family metadata tests retain custody/authority disclaimers. Relevant

and repository checks are recorded in the evidence report. No native code or
new native sanitizer path changes.

This removes the duplicate serial payload pass; it does not establish a final
whole-run ETA or qualified operator. Actual W/S classification, complete metadata
