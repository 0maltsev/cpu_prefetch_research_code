## Owned child, bounded diagnostics and no retry

Require a single-threaded main-process parent, default SIGCHLD disposition,
exclusive supervisor lease and actual subreaper. Block interruption signals
across fork/parent registration; restore the child's original mask after session
creation and default handlers. Before release, the child cannot start generation
or descendants. Verify its held PID/start identity, new session/group, inherited
cgroup, actual8GiB AS limit and CPU3 affinity. Close inherited namespace/other
descriptor copies without unlocking the parent's lease. Child-only file, FD
and core limits are installed and read back as well.

The parent releases this actual child over its private gate. It holds the leader
unreaped, drains at most64KiB diagnostics through a bounded pipe and rejects
overflow while retaining the bounded software-console prefix. On failure,
terminate/reap the owned session and escaped descendants using the accepted
held-leader/subreaper supervisor; cleanup remains inside the original source
deadline. Abnormal cleanup or any surviving/escaped descendant fails completion.

Before release, signal only the pinned pidfd and reap the held direct child.
If pidfd creation itself fails, WNOWAIT verifies that direct child before
signalling its unreaped PID; a single-threaded default-SIGCHLD parent cannot
recycle it before its own wait. No group or unrelated process is selected.
There are no automatic retries, adoption or clearing of partial directories.
Signals arriving immediately after fork still trigger owned cleanup. Failure
retains partial sources/progress; later failures never write into a foreign
replacement author directory. The qualified outer operator retains responsibility
for service-level supervision, all other stage ownership and restoration.
