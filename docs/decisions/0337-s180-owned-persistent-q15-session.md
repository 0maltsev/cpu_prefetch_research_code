# D337: owned persistent Q15-R/W for the S180 qualification route

Accepted engineering implementation under D310/D333/D335/D336. This connects
the separately verified signature boundary to the frozen native Q15 session;
it changes no scientific method, sample count, setting or deadline. The
immutable protocol, original seven resolutions, historical controllers and
native34247ce remain unchanged. This decision starts no stand action.

The qualified operator must first authenticate its complete profile, original
base replay and whole operational budget/ETA. Only its actual owned environment
and completed near/far clock handle can prepare this library. Preparation reads
CPU0's actual Unified L3 geometry and base page size; it does not substitute a
requested or cached platform value. The protected qualification directory is
created exclusively, physically bound and never adopted. Its original clock
qualification start/deadline and boot/24-hour window remain authoritative.
Preparation or evidence failure latches the environment to restoration only.

The parent durably records separate R/W attempts and verifies original-owner
SSHSIGs over independently derived inputs. Requests/context retain the existing
native v4 encoding. The exact frozen executable is sealed before dispatch,
with sealed R inputs, one output directory FD and a private framed W pipe.
Child-only limits remain 8GiB address space,8MiB memlock,64KiB per output file,
128 descriptors and no cores. CPU2 placement and actual owned cgroup membership
are checked before exec. The compaction owner registers the actual pidfd-bound
worker image. There is no report-selected backend, CLI, retry or profile
qualification in this component.

Native `write_exclusive` creates the ready pathname before writing and syncing
its bytes. The parent must not parse on pathname existence. On this fixed
x86-64 Linux route, it observes the live worker blocked in `read` of exactly the
first four-byte frame header on the actual private control pipe, matching pipe
device/inode and descriptor identity. The frozen source performs this read only
after durable ready publication. A live pidfd and one-task/no-children check
remain separate. Missing procfs access blocks qualification; there is no weak
file-existence fallback. The exact pipe barrier is checked again before W.

One persistent process retains the original private buffer. Before requesting
the W signature, the parent verifies R's exact result/request lineage, all five
physical artifacts and fixed schemas, full three-CPU prestate, runtime atomic
width/alignment/layout, residency counts for both probe regions, all four CPU
samples, actual prefetch capability mapping and the sealed waiting record.
The live worker must have one task, no children and the original reserved
membership; independently read actual MSRs must match the complete R prestate.
W signs that same session and exact R attempt/result hashes. The parent checks
the live barrier again before sending the two bounded native packets.

Console output is bounded to16KiB. Signing cannot outlive the original
qualification deadline or replace a foreign timer. W gets at most the existing
180 seconds, within the original qualification deadline and cleanup reserve.
Signals, failed signatures/evidence, timeout, nonzero exit or escaped descendants
stop and require owned held-leader/pidfd/subreaper cleanup. Partial files and
bounded diagnostics remain evidence. Existing environment/systemd recovery
handles hardware restoration only after independent worker quiescence.

Successful W requires the original result/artifact lineage, exact complete
prestate-or-mask apply and full prestate restore readbacks, existing native
accepted/integrity flags and ADR0150's unchanged counter ceiling2000. Zero exit
alone cannot pass. Independent post-exit MSR observations, empty owned cgroup,
no remaining children, compaction check, durable terminal receipt and original
deadline are required. Its receipt is evidence, not EXT008 admission, pilot
permission or scientific validity. The qualified semantic producer must still
replay and interpret it with all other required qualification evidence.

Reserve an explicit additional4MiB/40 inodes for at most32 protected Q15 files,
each at most64KiB, outside the archive quota. This covers full logical bytes and
4KiB/file allocation overhead. Live EXT009 rejects an external-commitment
declaration containing only the earlier D333 reserve. No shared archive quota
or stage cap is increased.

Verification uses an independently linked C++ pipe peer with an actual buffer,
real temporary SSHSIG keys, sealed inputs and real Linux process supervision.
Only platform observations and prerequisite clock evidence are explicit
software fixtures. The sanitizer peer needs ASan shadow address space and
sanitizer environment variables; that test bypasses the production AS limit
only in its private test boundary. Normal tests exercise the actual production
limits and stripped environment. No software fixture qualifies stand hardware.
